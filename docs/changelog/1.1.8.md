# Syntee Helper 1.1.8

- Большие каталоги MCP загружаются по запросу. Полный каталог можно вернуть в настройках контекста. Полные инструкции скиллов остаются доступны через поиск.
- Журнал мини-агентов хранится семь дней. Диагностика пишется в `userData/logs/debug.log` с ротацией.
- Подсказки и факты проверяются по исходным данным. В меню локальных моделей доступна Qwen2.5 Coder 1.5B Abliterated с проверкой SHA-256 при загрузке.
- Настройки получили стеклянные панели. Сборки Windows и Arch проходят тестовую ветку без автоматической публикации релиза.
