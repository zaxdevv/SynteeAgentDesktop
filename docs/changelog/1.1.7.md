# Syntee Helper 1.1.7

*Дата релиза: 28 ноября 2026*

Сборка форка на базе актуального upstream `dev` (475bafa), включая оркестрацию и карту кода. Предыдущие настройки MCP, Code Mode и журнал стоимости сохраняются.

- Watcher и автоматический поиск памяти учитывают проект, чат и включённые области памяти. В инкогнито постоянная память автоматически не подставляется, а Archivist пропускает запись. Явный поиск между проектами остаётся доступным по запросу.
- Janitor использует свежие результаты как опору для удаления старых повторов. Он пропускает повторную проверку неизменившегося контекста и сохраняет диагностические сообщения, diff и визуальные результаты. Уникальные результаты, свёрнутые в краткое описание, можно вернуть через `recall_context`.
- Оценка токенов переиспользует уже посчитанные сообщения. В Rust sidecar передаются только новые части запроса, а байты изображений и неоплачиваемые поля reasoning не копируются в ключ кеша.
- Локальная очередь сохраняет один слот для оперативной подсказки, пока Archivist обрабатывает предыдущий сеанс. Watcher и Navigator переиспользуют недавний проверенный ответ на одинаковый запрос.
- Windows x64 устанавливается через NSIS. Установщик форка сохраняет профиль Syntee Helper Desktop и переключает обновления на Releases форка. Для Arch x86_64 используйте пакет `.pkg.tar.zst` и `pacman -U`.

В тесте повторных поисков Janitor сократил текст результатов с 41 448 до 4 004 оценочных токенов. На том же входе upstream оставлял 6 168. Восемь одинаковых локальных проверок использовали одну генерацию в тесте очереди. Эти измерения относятся к фикстурам, скорость на конкретном CPU или GPU зависит от конфигурации.
